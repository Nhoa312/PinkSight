**Classification**: The application classifies ultrasound images into three categories:
-Benign
-Malignant
-Normal
 
**Dataset**: The BUSI (Breast Ultrasound Images) dataset was used to train and evaluate the model.

**How It Works**: PinkSight loads a breast ultrasound image and uses a trained AI model to display a classification result and its confidence score.

**Disclaimer**

PinkSight is an academic and experimental project. It is not intended for medical diagnosis and does not replace professional medical evaluation.
